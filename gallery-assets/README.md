# Design gallery assets

All 46 captures, including three current project journal views, are published here for the [gallery](../gallery.html). The local originals remain in the separate design-captures folder. Keeping these assets inside this project makes the gallery work from a local file, a GitHub Pages repository subpath, or another static host.

`captures.json` supplies the display order, categories, and descriptive captions. `scripts/build-gallery.cjs` generates the static HTML cards from it. Run that script after updating the manifest; no build step is required to view the committed gallery.

The images span earlier iterations and the current project journal. Some screenshots contain illustrative Unsplash portraits, with fictional names and affiliations. See [third-party notices](../THIRD_PARTY_NOTICES.md) and [portrait sources](../journal-assets/README.md); the photographs retain their own license.

The README overview at `docs/images/gallery-overview.jpg` is a browser screenshot of the gallery’s Overview layout with all filters cleared. Refresh it after adding captures.
